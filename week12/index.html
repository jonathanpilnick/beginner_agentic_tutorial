Week 12

Web Interfaces with Flask & Streamlit

Four days: three labs and a project. Each page has one prompt to paste into Claude Code. Your AI tutor takes it from there.

  • Lab 1 · Day 1
    Your agent gets an API
    Set up the kit, then put your Week 11 assistant behind a Flask web API: JSON routes, status codes, an endpoint that serves AI, and a Python client that calls your running server.
  • Lab 2 · Day 2
    A web page for your assistant
    Settings and a secret token from a .env file, a chat that remembers you, a route only the token can use, and an HTML and JavaScript page that talks to your API.
  • Lab 3 · Day 3
    The same assistant in Streamlit
    The same brain and memory as Lab 2, as a Streamlit chat app in a few dozen lines of Python: reruns, st.session_state, chat elements and a memory sidebar with Forget buttons.
  • Project · Day 4
    Ship it
    A web AI app of your own choice, built with Flask or Streamlit from a working starter: your own AI feature, input checks, settings and secrets in .env, tests, a write-up, peer review and a demo.
