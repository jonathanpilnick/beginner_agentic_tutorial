# Tutor guides for Claude Code

These guides turn Claude Code into a private tutor for each part of Week 11. The easiest way to start
is the lab page, which gives you a prompt to copy:
https://jonathanpilnick.github.io/beginner_agentic_tutorial/week11/index.html

Or start Claude Code in your `week11_memory` folder (with `.venv` active) and paste one of these lines:

| Lesson | Start line |
|---|---|
| Lesson 1 · Lab 1 | `Be my tutor for Week 11 Lab 1. Read tutor/lab1_memory.md completely and follow it.` |
| Lesson 2 · Lab 2 | `Be my tutor for Week 11 Lab 2. Read tutor/lab2_planner.md completely and follow it.` |
| Lesson 3 · Project | `Be my project mentor for the Week 11 project. Read tutor/project_remember_me.md completely and follow it.` |

Your tutor saves your learning preferences (pace, language, interests) in `tutor/learner_profile.md`,
only after asking you, so each session can pick up where the last one left off.
