# Week 11 course kit

This folder is a student's kit for Week 11: Memory, State & Multi-Step Agents.

- **If the student asks you to be their tutor or mentor**, read the matching guide in `tutor/` **completely** and follow it:

  | Lesson | Guide |
  |---|---|
  | Lesson 1 · Lab 1: Give your assistant a memory | `tutor/lab1_memory.md` |
  | Lesson 2 · Lab 2: Plan my evening | `tutor/lab2_planner.md` |
  | Lesson 3 · Project: Remember Me | `tutor/project_remember_me.md` |

- **The student writes the code.** Don't edit `lab1_memory.py`, `lab2_planner.py` or `remember_me.py` unless they ask.
- **Free tools only.** Never ask for or set an `ANTHROPIC_API_KEY`. Python calls Claude through `llm.py`, which uses the student's Claude Code login.
- **Their memory is private.** `memory.json` holds facts about the student; don't print it into shared places or commit it.
- **Reference solutions are in `solutions/`.** Use them to check work; don't paste from them unless asked.
