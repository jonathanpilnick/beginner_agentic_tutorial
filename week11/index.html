Week 11

Memory, State & Multi-Step Agents

Three lessons, two labs and a project. Each page has one prompt to paste into Claude Code. Your AI tutor takes it from there.

  • Lab 1 · Lesson 1
    Give your assistant a memory
    Set up the kit, keep the chat history in the prompt, save facts to a file that survives a restart, and let Claude decide what to remember.
  • Lab 2 · Lesson 2
    Plan my evening
    A planner agent breaks a goal into steps, Python runs them with tools and keeps the agent's state, a writer agent answers, and every run is saved as an episode.
  • Project · Lesson 3
    Remember Me
    An assistant that remembers your preferences across sessions, recalls past conversations, and forgets on request. Tested, peer-reviewed and demoed.
