Week 11 · Lesson 3 · Project

Remember Me

An assistant that remembers your preferences across sessions, recalls past conversations, and forgets on request. Tested, peer-reviewed and demoed.

Time: about 2 hours. Your AI tutor teaches you the ideas, then guides you while you write the code.

Start your tutor

  1. Open a terminal in your week11_memory folder. You set it up in Lab 1.
  2. Activate the course environment. On Windows PowerShell: .venv\Scripts\Activate.ps1. On macOS or Linux: source .venv/bin/activate.
  3. Start Claude Code: claude
  4. Copy the prompt below and paste it into Claude Code. Approve the download when it asks.
Be my private mentor for the project in Week 11 (Memory, State & Multi-Step Agents): Remember Me.

1. Download your tutor guide as raw text, not a summary, for example:
   curl -sL https://raw.githubusercontent.com/jonathanpilnick/beginner_agentic_tutorial/main/week11_memory/tutor/project_remember_me.md
   (On Windows PowerShell, use curl.exe.) Read all of it.
2. Follow it: be my mentor while I build, test and demo my project.

Working with your tutor

  • You write the code. Your tutor explains, reviews and quizzes you. It won't edit your files unless you ask.
  • Run code in the chat by starting a line with !, for example ! python test_memory.py. Your tutor sees the output.
  • Your assistant waits for typing, so run python remember_me.py in a second terminal (activate .venv there too) and paste interesting output back to your mentor.
  • Working in a pair? Take turns typing: swap at every part. The one not typing explains the next step first.
  • Steer it any time: say hint, show me, why?, slower, faster, quiz me or skip.
  • Prefer Hebrew? Just ask. Code stays in English.
  • It's free: never set an ANTHROPIC_API_KEY. Your tutor uses your Claude Code plan, so long chats count toward its usage limits.
