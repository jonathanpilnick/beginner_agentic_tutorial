# Beginner Agentic Tutorial

Hands-on labs from the Aardvark AI developer program, where **Claude Code is your private tutor**.

Each lab includes a tutor guide written for Claude Code. Claude reads it and then teaches you step by step:
- It explains what you're building and why it matters.
- It adapts to your pace, your language (English or Hebrew) and your interests.
- **You** write the code; Claude guides, reviews and quizzes you.

**What you need:** a computer and a Claude Code login (Pro or Max plan). Everything else is free and open source. No API keys.

## Weeks

| Week | Topic | Start here |
|---|---|---|
| 10 | Retrieval-Augmented Generation (RAG): embeddings, vector databases, chunking, evaluation, cited answers, and a Q&A bot over your own documents | [week10_rag](week10_rag/README.md) |

## Start in one minute

1. **Get the repo:** `git clone https://github.com/jonathanpilnick/beginner_agentic_tutorial.git`, or **Code → Download ZIP**.
2. **Open a terminal** in `beginner_agentic_tutorial/week10_rag` and run `claude`.
3. **Paste:** `Be my tutor for Week 10 Lab 0. Read tutor/lab0_setup.md completely and follow it.`

All start lines are in [week10_rag/tutor/README.md](week10_rag/tutor/README.md).
