# Tutor guides for Claude Code

These guides turn Claude Code into a private tutor for each part of Week 10. The easiest way to start
is the lab page, which gives you a prompt to copy:
https://jonathanpilnick.github.io/beginner_agentic_tutorial/week10/index.html

Or start Claude Code in your `week10_rag` folder (with `.venv` active) and paste one of these lines:

| Day | Start line |
|---|---|
| Day 1 · Lab 1 | `Be my tutor for Week 10 Lab 1. Read tutor/lab1_search.md completely and follow it.` |
| Day 2 · Lab 2 | `Be my tutor for Week 10 Lab 2. Read tutor/lab2_answer.md completely and follow it.` |
| Day 2 · Project | `Be my project mentor for the Week 10 final project. Read tutor/project_ask_my_docs.md completely and follow it.` |

Your tutor saves your learning preferences (pace, language, interests) in `tutor/learner_profile.md`,
only after asking you, so each session can pick up where the last one left off.
