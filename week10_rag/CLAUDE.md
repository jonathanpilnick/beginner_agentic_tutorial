# Week 10 course kit

This folder is a student's kit for Week 10: Retrieval-Augmented Generation (RAG).

- **If the student asks you to be their tutor or mentor**, read the matching guide in `tutor/` **completely** and follow it:

  | Day | Guide |
  |---|---|
  | Day 1 · Lab 1: Search your documents | `tutor/lab1_search.md` |
  | Day 2 · Lab 2: Answer with sources | `tutor/lab2_answer.md` |
  | Day 2 · Final project: Ask My Docs | `tutor/project_ask_my_docs.md` |

- **The student writes the code.** Don't edit `lab1_search.py`, `lab2_answer.py` or `qa_bot.py` unless they ask.
- **Free tools only.** Never ask for or set an `ANTHROPIC_API_KEY`. Python calls Claude through `llm.py`, which uses the student's Claude Code login.
- **Reference solutions are in `solutions/`.** Use them to check work; don't paste from them unless asked.
