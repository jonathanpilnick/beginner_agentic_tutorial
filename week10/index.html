Aardvark · Week 10

Retrieval-Augmented Generation (RAG)

Each lab page has one prompt to paste into Claude Code. Your AI tutor takes it from there.

  • Lab 0 · Lesson 1
    Set up the kit
    Download the course kit, create the Python environment, and prove Python can talk to Claude through your Claude Code login.
  • Lab 1 · Lesson 1
    Embeddings: search without a database
    Turn sentences into 384 numbers each and build a search that finds the right answer with zero shared words.
  • Lab 2 · Lesson 2
    ChromaDB basics
    Use a real vector database: store, search, filter, update, and watch it remember after Python closes.
  • Lab 3 · Lesson 2
    The ingestion pipeline
    Load .md, .txt and PDF files, split them into overlapping chunks, and store them with sources and page numbers.
  • Lab 4 · Lesson 2
    Measuring retrieval
    Build a tiny benchmark (hit@1, hit@3, MRR) and find out which chunk size really works best. No LLM, no cost.
  • Lab 5 · Lesson 3
    Grounded, cited answers
    Retrieve, build the prompt, and let Claude answer with citations. It says “I don’t know” instead of making things up.
  • Project · Lesson 3
    Q&A bot over your own documents
    Build your own private search assistant over your notes: citations, refusals, /sources and a 3-minute demo.
